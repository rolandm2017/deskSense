Our purpose is to develop a new feature. We will discuss what the feature will do, and not do.

During our discussion, you will use the /grill-me skill to uncover hidden requirements and think through implementation details.

We will endeavour to plan out how we can write testable code, bug free and usable, both from a user perspective and a developer experience perspective.

We will go through 2-4 rounds of questions, possible more if there is a lot to consider.

We will create a spec file for the feature together. The spec file will live in /spec. It will have a name and a date as yyyy-mm-dd.

Once we have created the spec, and I have reviewed it, we'll move on to using a developer agent to write the spec using /developer.

After the developer agent is done, we will run a /code-review agent to catch bugs, and reduce spec drift.

After the code review agent is done, we will use /qa to run quality assurance on the feature. QA will be done in the form of running tests, but also by running the code individually with arguments.
