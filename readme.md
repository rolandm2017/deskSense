# what is Desksense?

a program that tracks how I spend my time.

programs, chrome tabs. entertainment vs productivity.

Allows the user to become content or discontent with how they spent their day, week, month.

## use cases

Tracking how much time I spend coding.

Tracking how much time I spend coding *per project*, eventually.

Tracking how much time I spend on language learning.

## Expected UI

The UI will let the user create their own categories using tickboxes.

You tick the programs and websites that contribute to behavior X. Program now tracks how much time you spend doing X per day or per week.
